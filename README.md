# 学生成绩进步评分系统

基于 Streamlit 的学生成绩分析工具，用于合并多次考试数据、计算进步和排名奖励、检测偏科，并导出 Excel 结果。

本文档以当前 `web` 分支代码为准，文档更新日期：2026-10-13。最近一次功能更新：新增限定年级排名内持平计入连续进步。完整操作说明见 [使用说明](使用说明.md)。

## 快速开始

项目的 `.python-version` 声明 Python 3.11。请在项目根目录执行以下命令，安装依赖后启动网页应用：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

这里的 `python` 应指向你准备使用的 Python 环境；如果本机使用 `python3`，两条命令均改用 `python3`。保持在项目根目录运行，评分模块导入和配置文件路径依赖当前工作目录。

默认访问地址为 <http://localhost:8501>，以终端实际输出为准。本仓库目前没有 `启动程序.sh` 或 `build_mac_lite.py`，也没有随仓库提供的独立应用安装包。

依赖以 [requirements.txt](requirements.txt) 为准：

| Streamlit | `==1.51.0` |

## 功能与流程

- 上传多次考试成绩，编辑考试名称，按上传顺序分析。
- 上传历史成绩总表，接续新的考试；也可以仅分析历史总表。
- 在侧边栏调整区间权重、年级和集团排名奖励、A/B 线奖励、连续进步奖励、总分奖励、状元奖和偏科参数。
- 在总览、进步分析、偏科检测、学生详情、得分详情、导出结果六个标签页查看结果。
- 下载原始成绩总表和完整分析结果，留存并供后续使用。

典型操作：启动应用 → 核对参数 → 上传历史总表（可选）→ 按时间顺序上传新成绩 → 修改考试名称 → 开始分析 → 查看结果 → 下载 Excel。

分析后参数和考试名称会锁定。需要重新分析时，点击“重置”并重新上传数据；此操作清除当前上传和分析结果，保留评分参数。上传的考试数据不会因为下次打开应用而自动恢复，需要自行下载并重新上传历史总表。

## 输入格式

文件上传仅接受 `.xlsx`。新成绩文件读取第一个工作表，代码提供四种列数的导入分支：

| 格式 | 列结构 | 当前情况 |
| --- | --- | --- |
| 2 列 | 姓名、排名 | 支持年级排名评分及连续进步 |
| 3 列 | 姓名、排名、总分 | 增加总分奖励 |
| 9 列 | 姓名、排名、总分、语文、数学、英语、物理、化学、生物 | 增加偏科分析 |
| 22 列 | 姓名 + 总分的分数／年级排名／集团排名 + 六科各自的分数／年级排名／集团排名 | 当前优先使用的格式 |

22 列格式要求使用规定列名，例如 `总分年级排名`、`总分集团排名`、`语文年级排名`；每名学生一行，姓名用于跨考试合并。请保持各次新上传成绩格式一致。详细列顺序和历史总表格式见 [数据格式说明](使用说明.md#数据格式说明)。

## 当前评分规则

```text
总得分 = 区间进步得分 + 连续进步加分 + 年级排名加分
       + 集团排名加分 + 总分奖励 + 东校状元奖 + 偏科扣分
```

“偏科扣分”在结果中是负数。主要规则如下：

- 区间进步分只计算本次与上一次有效排名之间的提升，按跨越名次的权重求和。
- 连续进步默认包含年级前 100 名（含）内的持平，每次符合条件的持平增加 1 次；可在“连续进步奖励”中关闭或调整前 N 名范围。范围外持平或退步归零，排名提升始终计入。奖励取当前次数对应档位，不累加之前各次奖励。符合条件的持平计入总览的进步人数，区间进步分仍为 0；集团排名不参与该限定规则。
- 年级和集团排名奖励各取满足条件的最小排名阈值对应的奖励。
- 年级排名加分包含 A/B 线奖励：当前排名达标即可获得，两条线只取较高的一项，与年级排名档位奖励叠加。
- 总分必须严格大于阈值，取满足条件的最大奖励。
- 最新年级排名第 1 名获得独立状元奖，默认 200 分，可与其他奖励叠加。
- 偏科依据各科得分率相对参考线的差值标准差判断；化学和生物合并为“选科”。

默认参数、缺考处理和计算示例见 [使用说明](使用说明.md)。

## 导出文件

| 下载文件 | 内容 | 用途 |
| --- | --- | --- |
| `成绩总表.xlsx` | 每次考试一个工作表，加一个“完整总表”工作表 | 留存原始数据，下次作为历史总表上传 |
| `完整分析结果.xlsx` | “完整结果”“得分明细”“连续进步规则”，有科目数据时另含“偏科检测” | 查看和保存本次分析结果 |

导出通过页面下载按钮完成。完整分析结果不适合作为历史成绩总表上传。

## 已知限制与验证范围

- **偏科默认值不一致**：首次初始化的标准差阈值为 `15 / 30 / 60`，“恢复默认”设置为 `7.5 / 8.5 / 10.0`。分析前应明确核对界面参数。
- **配置恢复不完整**：保存配置和手动加载包含状元奖参数，自动恢复路径遗漏它。浏览器配置回传是否成功尚未验证；不要仅依据“配置已保存”提示判断恢复成功。服务器备用文件为 `config/user_settings.json`。
- **按姓名合并**：没有学号字段用于区分同名学生，请确保同一次考试中姓名唯一、跨考试写法一致。
- **运行验证范围**：2026-10-13 使用隔离的本地 Python 3.12 环境和 Streamlit 1.51.0，通过 16 项规则及集成测试，覆盖四种上传格式、历史总表、进步人数和缺考、六个页面的 AppTest 执行、配置文件保存／加载／恢复默认、真实 Excel 导出和再导入。未执行线上部署或真实浏览器的 localStorage 恢复验证。

这些问题仅记录在文档中，尚未修复。其他数据处理限制见 [使用说明](使用说明.md#已知问题与常见问题)。
