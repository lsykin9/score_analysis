# 学生成绩进步评分系统

## 📖 项目简介

这是一个用于追踪和评估学生成绩进步情况的自动化评分系统。系统会根据学生的排名变化、连续进步次数等多个维度进行综合评分，鼓励学生持续进步。

## ✨ 主要功能

- **成绩追踪**：自动累积每次考试成绩，建立历史记录
- **区间加权评分**：不同排名区间有不同的进步权重
- **排名奖励**：达到特定排名阈值时获得额外加分
- **连续进步奖励**：连续多次进步可获得累加奖励
- **灵活配置**：所有评分规则通过Excel配置文件管理

## 📋 使用要求

- Python 3.x
- pandas
- openpyxl

安装依赖：
```bash
pip install pandas openpyxl
```

## 📂 文件说明

- `score_chain_auto_v6.py` - 主程序文件
- `参数配置.xlsx` - 评分规则配置文件（需自行创建）
- `最新成绩.xlsx` - 本次考试成绩输入文件（需自行创建）
- `成绩总表.xlsx` - 自动生成的历史成绩汇总
- `进步链分析结果.xlsx` - 自动生成的评分详情
- `最终得分结果.xlsx` - 自动生成的最终排名结果

## 🚀 使用方法

1. 准备 `参数配置.xlsx` 文件，设置各项评分规则
2. 准备 `最新成绩.xlsx` 文件，包含本次考试成绩
3. 运行程序：
   ```bash
   python score_chain_auto_v6.py
   ```
4. 查看生成的结果文件

## 📊 评分维度

1. **区间进步得分**：根据排名提升的幅度和所在区间权重计算
2. **排名加分**：达到特定排名（如前10、前20）的奖励
3. **连续进步加分**：连续多次考试排名都在进步的累计奖励

## 📝 配置文件格式

`参数配置.xlsx` 应包含以下配置项：
- 区间权重：A_前20、B_21-50、C_51-100等
- 排名奖励：前10奖励、前20奖励等
- 连续进步奖励：连续进步第1次奖励、连续进步第2次奖励等
- 分数线：line（如430）
- 过线奖励：过线奖励
