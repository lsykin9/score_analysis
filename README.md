# 学生成绩进步评分系统

一个基于Web的学生成绩进步评分系统，可以帮助老师分析学生的进步情况，并给出量化的评分。

## 📁 项目结构

```
score analysis/
├── app.py                      # 主程序 - Web界面
├── score_analysis_v0_1.py      # 评分算法核心
├── requirements.txt            # 依赖包列表
├── 启动程序.sh                 # macOS启动脚本（双击运行）
├── build_mac_lite.py           # macOS打包脚本（可选）
├── 使用说明.md                 # 详细使用说明
└── README.md                   # 本文件
```

## 🚀 快速开始

### macOS用户（推荐）

**最简单的方式：**
1. 双击 `启动程序.sh` 
2. 浏览器自动打开程序界面
3. 开始使用！

### 手动启动

```bash

# 2. 启动程序
streamlit run app.py
```

### 访问地址

程序启动后，浏览器会自动打开：
- 本地地址：http://localhost:8501

## 📖 功能特点

- ✅ **多维度进步评分**：区间进步、排名奖励、连续进步
- ✅ **自动追踪历史成绩**：累积所有考试数据
- ✅ **偏科检测与分析**：识别学科短板
- ✅ **可视化图表展示**：直观的数据呈现
- ✅ **参数可配置**：内嵌参数调整界面
- ✅ **Excel数据导入导出**：方便的数据管理
- ✅ **学生个人详情查看**：多维度分析单个学生

## 📊 评分规则

**总得分 = 区间进步得分 + 排名加分 + 连续进步加分 + 总分奖励 + 偏科扣分**

### 主要评分维度

1. **区间进步得分**：根据排名进步幅度和所在区间计算
2. **排名加分**：前10/20/30/50/100名获得额外加分
3. **连续进步加分**：连续多次进步有累积奖励
4. **总分奖励**：考试总分超过阈值获得奖励
5. **偏科扣分**：严重偏科会有相应扣分

详细说明请查看 `使用说明.md`

## 🎯 使用流程

1. **调整参数**（可选）：在侧边栏调整评分参数
2. **上传历史数据**（可选）：上传之前的成绩总表
3. **上传新成绩**：依次上传各次考试Excel文件
4. **开始分析**：点击"开始分析"按钮
5. **查看结果**：在不同标签页查看分析结果
6. **导出数据**：下载Excel格式的分析报告

## 📂 数据格式

系统支持三种Excel数据格式：

### 格式1：仅排名（2列）
| 姓名 | 排名 |
|------|------|
| 张三 | 15   |

### 格式2：排名+总分（3列）
| 姓名 | 排名 | 总分 |
|------|------|------|
| 张三 | 15   | 650  |

### 格式3：排名+总分+各科成绩（9列）
| 姓名 | 排名 | 总分 | 语文 | 数学 | 英语 | 物理 | 化学 | 生物 |
|------|------|------|------|------|------|------|------|------|
| 张三 | 15   | 650  | 110  | 120  | 115  | 95   | 105  | 105  |
