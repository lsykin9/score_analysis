# 学生成绩进步评分系统

## 📖 项目简介

这是一个用于追踪和评估学生成绩进步情况的自动化评分系统。系统会根据学生的排名变化、连续进步次数等多个维度进行综合评分，鼓励学生持续进步。

## ✨ 主要功能

- **成绩追踪**：自动累积每次考试成绩，建立历史记录
- **支持总分数据**：可同时记录排名和总分信息
- **区间加权评分**：不同排名区间有不同的进步权重
- **排名奖励**：达到特定排名阈值时获得额外加分
- **连续进步奖励**：连续多次进步可获得累加奖励
- **总分奖励**：总分超过特定阈值可获得额外奖励
- **灵活配置**：所有评分规则通过Excel配置文件管理

## 📋 使用要求

- Python 3.x
- pandas
- openpyxl

安装依赖：
```bash
pip install pandas openpyxl
```

## 📂 文件说明

- `score_analysis_v0.1.py` - 主程序文件
- `参数配置.xlsx` - 评分规则配置文件（需自行创建）
- `最新成绩.xlsx` - 本次考试成绩输入文件（需自行创建，支持2列/3列/9列格式）
- `成绩总表.xlsx` - 自动生成的历史成绩汇总
- `进步链分析结果.xlsx` - 自动生成的评分详情
- `最终得分结果.xlsx` - 自动生成的最终排名结果
- `使用说明.md` - 详细的功能使用说明和数据格式示例

## 🚀 使用方法

1. 准备 `参数配置.xlsx` 文件，设置各项评分规则
2. 准备 `最新成绩.xlsx` 文件，包含本次考试成绩
   - 支持2列格式：姓名、排名
   - 支持3列格式：姓名、排名、总分
   - 支持9列格式：姓名、排名、总分、语文、数学、英语、物理、化学、生物
3. 运行程序：
   ```bash
   python score_analysis_v0.1.py
   ```
4. 查看生成的结果文件

详细说明请查看 `使用说明.md` 文件。

## 📊 评分维度

1. **区间进步得分**：根据排名提升的幅度和所在区间权重计算
2. **排名加分**：达到特定排名（如前10、前20）的奖励
3. **连续进步加分**：连续多次考试排名都在进步的累计奖励
4. **总分奖励**：考试总分超过特定阈值的奖励（可选）

## 📝 配置文件格式

`参数配置.xlsx` 应包含以下配置项：
- 区间权重：A_前20、B_21-50、C_51-100等
- 排名奖励：前10奖励、前20奖励等
- 连续进步奖励：连续进步第1次奖励、连续进步第2次奖励等
- 总分奖励：总分大于600奖励、总分大于650奖励等（可选）
- 分数线：line（如430）
- 过线奖励：过线奖励

`最新成绩.xlsx` 支持三种格式：
- 格式1（2列）：姓名、排名
- 格式2（3列）：姓名、排名、总分
- 格式3（9列）：姓名、排名、总分、语文、数学、英语、物理、化学、生物

详见 `使用说明.md` 文件，包含完整的格式说明和Python创建代码示例。
